# 기후탐정 내러티브 통합 설계

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 3개 독립 섹션을 "박보닥씨의 오늘 출근길" 스토리로 통합하여 앱의 내러티브를 일관되게 만든다.

**Architecture:** 코드 로직 변경 없이 `app.py`의 텍스트(헤더, 캡션, 히어로, 섹션 제목)와 몬테비데오 UI 컴포넌트만 수정한다. 분석 모듈(`anomaly.py`, `correlation.py`, `collector.py`)은 건드리지 않는다.

**Tech Stack:** Streamlit, Python, HTML (inline), Plotly

---

## 설계 결정

### 주인공 설정
- 이름: 박보닥씨
- 나이: 35세
- 특징: 문정역 인근 회사 직장인, AI에 관심 많은 일반인
- 앱 톤: 기후탐정(AI)이 박보닥씨에게 **정중한 2인칭 존댓말**로 말 거는 방식

### 내러티브 흐름
1. 히어로: 기후탐정이 박보닥씨의 출근길을 분석했다고 인사
2. 섹션 1: 오늘 날씨 → 이상한가? → 지하철 예측 순으로 자연스럽게 연결

## 변경 사항 상세

### 1. 히어로 (`render_hero`)

**현재:**
```
🌌 기후탐정
지구 양 끝 날씨 비교 · 이상 기후 탐지 · 도시 데이터 상관분석
📍 문정역, 서울 ↔ 📍 몬테비데오, 우루과이
```

**변경 후:**
```
🚇 기후탐정
박보닥씨의 오늘 출근길을 분석했어요
📍 문정역, 서울 출근 날씨 리포트
```

### 2. 섹션 1 — 날씨 현황

- **헤더:** `"☀️ 박보닥씨, 오늘 문정역 날씨예요"`
- **캡션:** 제거 (헤더가 충분히 직관적)
- **문정역 컬럼:** 현재 구조 유지 (기온/강수/습도/풍속 + 감성 멘트)
- **몬테비데오:** 기존 col2 전체 → `<details>` 접이식 미니 카드로 교체
  ```
  🌏 지구 반대편은? (클릭)
  └ 몬테비데오 · 22°C · 구름 조금
  ```
  - `st.columns(2)` 제거, 문정역만 단일 컬럼으로 크게 표시
  - 몬테비데오는 문정역 블록 아래 `st.expander`로 표시

### 3. 섹션 2 — 이상 기후 탐지

- **헤더:** `"🚨 근데 오늘 좀 이상한 날씨 아닌가요?"`
- **캡션:** `"박보닥씨의 최근 90일 출근길 날씨를 AI가 분석했어요. 보라색 점이 많을수록 요즘 날씨가 심상치 않아요."`
- **결과 멘트:**
  - 이상치 있을 때: `"최근 90일간 {n}번의 이상한 날씨가 있었어요. 오늘 출근길, 조심하세요!"`
  - 정상일 때: `"최근 90일간 날씨는 평온했어요. 오늘도 무난한 하루 될 것 같아요 😊"`

### 4. 섹션 3 — 지하철 상관관계

- **헤더:** `"🚇 이 날씨에 지하철 얼마나 붐빌까요?"`
- **캡션:** `"날씨와 문정역 지하철 이용객 수를 분석했어요. 오늘 같은 날씨, 지하철이 더 붐빌까요?"`

## 구현 범위

**수정 파일:** `app.py`만 수정
- `render_hero()` 텍스트 변경
- `main()` 내 섹션 헤더/캡션 텍스트 변경
- 섹션 1의 `st.columns(2)` → 단일 컬럼 + `st.expander` 로 몬테비데오 이동
- 섹션 2, 3 결과 멘트 톤 변경

**변경 없는 파일:** `data/`, `analysis/`, `commentary/`, `assets/`, `tests/`
